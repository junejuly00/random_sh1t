# Changelog

## v1.0.0 - 2026-08-19

- Initial release.
- 16-step beat sequencer (Kick, Snare, Hi-Hat, Clap, Tom) with switchable
  synth / sample drum sources.
- 16-step, two-octave melody piano roll with sine/triangle/square/sawtooth
  waveforms.
- Tempo control (60-200 BPM).
- Save/Load pattern via `localStorage`.
- Record playback to a downloadable `.webm` file.
- Advanced mode: 16/32-step melody width, live MIDI input play-through, and
  MIDI export to a downloadable `.mid` file.
